# 多平台分发文案

把主教程拆成各平台原生文案，方便手动分发引流。每篇都已嵌入对应平台的 UTM 链接。

| 文件 | 平台 | 用途 |
| --- | --- | --- |
| [zhihu.md](./zhihu.md) | 知乎 | 回答 / 文章，答 "国内怎么开通 ChatGPT Plus" 类问题 |
| [xiaohongshu.md](./xiaohongshu.md) | 小红书 | 图文笔记，配 9 宫格 |
| [x-thread.md](./x-thread.md) | X / Twitter | 7 条串，面向海外华人 |
| [reddit.md](./reddit.md) | Reddit | r/ChatGPT 等，讨论向，注意 10% 自推广规则 |

**发布建议**
- 知乎：工作日晚 8–11 点，配对比表截图，结尾引导点赞收藏。
- 小红书：周末或晚高峰，标题带 emoji，正文短句多换行。
- X：早 9–11 点或下午 1–3 点发串。
- Reddit：美东早 8–10 点，先在社区多输出价值，避免被判硬广。
