# 多平台分发文案

把主教程拆成各平台原生文案，方便手动分发引流。每篇都已嵌入对应平台的 UTM 链接。

> 最后更新：2026-10-26（和主教程同一天：GPT-6、价格、截图、开发票都已同步）

| 文件 | 平台 | 用途 |
| --- | --- | --- |
| [zhihu.md](./zhihu.md) | 知乎 | 回答 / 文章，答「ChatGPT Plus 怎么充值」「付款被拒怎么办」「代充靠谱吗」类问题 |
| [xiaohongshu.md](./xiaohongshu.md) | 小红书 | 图文笔记，直接用 `image/` 里的实拍截图拼 9 宫格 |
| [x-thread.md](./x-thread.md) | X / Twitter | 8 条串，中文 |
| [reddit.md](./reddit.md) | Reddit | r/ChatGPT 等，讨论向，注意 10% 自推广规则 |

**发布建议**
- 知乎：工作日晚 8–11 点，配对比表截图和充值页截图，结尾引导点赞收藏。
- 小红书：周末或晚高峰，标题带 emoji，正文短句多换行。
- X：早 9–11 点或下午 1–3 点发串。
- Reddit：美东早 8–10 点，先在社区多输出价值，避免被判硬广。

**统一口径（发之前对一遍）**
- 价格以主教程价格表为准：Plus 约 ¥148、Pro 5x 约 ¥800、Pro 20x 约 ¥1380（美元结算，人民币是约数）。
- 付款只写支付宝，不写微信。
- 不写「国内用户」「国内怎么开」这类说法，统一说「没有美金卡」「付款老被拒」。
- 不写「不会封号」「100% 成功」这类打包票的话。
